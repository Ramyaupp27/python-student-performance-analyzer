Student Performance Analyzer
Beginner Python Data Analytics Practice Project
Project Overview
The Student Performance Analyzer is a beginner-level Python project that analyzes sample student marks. It calculates total and average marks, identifies pass/fail status, finds the highest and lowest marks, demonstrates basic data transformation and filtering, and generates a report for each student.
Objectives
- Practice Python dictionaries and lists.
- Build reusable functions with parameters and return values.
- Use if-else conditions to determine pass/fail status.
- Calculate totals, averages, minimums, and maximums.
- Use lambda with map() and filter().
- Use a for loop to generate reports for multiple students.
Dataset
The project uses sample marks for five students:
Student	Marks
Ramya	85, 90, 78, 95, 88
John	45, 55, 60, 40, 50
Priya	92, 95, 89, 96, 98
David	35, 40, 45, 50, 38
Sarah	70, 75, 80, 85, 90


Pass/fail rule: An average of 50 or above is PASS; an average below 50 is FAIL.
Features
1. Calculate total marks for a student.
2. Calculate average marks for a student.
3. Determine pass/fail status.
4. Find the highest and lowest subject marks.
5. Add 5 marks to each mark using map() and a lambda expression (demonstration only; original data remains unchanged).
6. Filter subject marks greater than or equal to 50 using filter().
7. Generate a performance report for all students.

How to Run
1. Download or clone this repository.
2. Open student_performance_analyzer.ipynb in Jupyter Notebook, JupyterLab, or Google Colab.
3. Run the notebook cells from top to bottom.
No external Python packages are required for the project code; it uses Python built-in functionality.
