# Student Performance Analyzer

**Beginner Python Data Analytics Project**

## 1. Project Overview

The Student Performance Analyzer is a Python project developed to analyze student marks and generate performance reports.

The project calculates total marks, average marks, pass/fail status, and identifies the highest and lowest marks for each student.

## 2. Project Objectives

- Practice Python dictionaries and lists.
- Create reusable functions.
- Apply conditional statements and loops.
- Perform basic calculations and data analysis.
- Use lambda expressions with `map()` and `filter()`.
- Generate student performance reports.

## 3. Dataset

The project uses sample marks for five students.

| Student | Subject Marks |
|---|---|
| Ramya | 85, 90, 78, 95, 88 |
| John | 45, 55, 60, 40, 50 |
| Priya | 92, 95, 89, 96, 98 |
| David | 35, 40, 45, 50, 38 |
| Sarah | 70, 75, 80, 85, 90 |

**Pass/Fail Criteria:**
- Average marks greater than or equal to 50: PASS
- Average marks below 50: FAIL

## 4. Project Features

1. Calculate total marks.
2. Calculate average marks.
3. Determine student pass/fail status.
4. Find highest and lowest subject marks.
5. Increase marks using `map()` and lambda.
6. Filter subject marks using `filter()`.
7. Generate individual student performance reports.
